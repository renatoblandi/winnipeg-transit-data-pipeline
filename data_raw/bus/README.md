# Raw Transit Performance Data

This folder contains the raw public transit on-time performance dataset used in the project.

## Source
City of Winnipeg Open Data Portal  
Dataset: "On-Time Performance By Day (Past Year)"  
URL: https://data.winnipeg.ca/Transit/On-Time-Performance-By-Day-Past-Year/4ts9-esxd

## Description
This dataset includes daily aggregated performance metrics for Winnipeg bus routes, such as:
- Early stops
- Late stops
- On-time stops
- Route information
- Service day type

## Notes
The file in this folder is stored in its original format and has not been modified.  
All cleaning and transformation steps are performed in the data processing notebooks.
